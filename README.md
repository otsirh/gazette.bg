# gazette.bg

Кратки обобщения на всеки брой на Държавен вестник на разбираем език — [gazette.bg](https://gazette.bg).

Държавен вестник е официалното издание, в което се обнародват законите и другите
нормативни актове на Република България. Всеки брой е десетки, понякога стотици
страници правен текст. gazette.bg го обобщава с изкуствен интелект (Claude на
Anthropic), за да видите за минути какво ви засяга.

Сайтът е неофициален и не е свързан с държавни органи. Обобщенията може да
съдържат грешки и нямат правна сила. Официалният текст е на
[dv.parliament.bg](https://dv.parliament.bg).

Забелязахте грешка в обобщение? [Съобщете за нея](https://github.com/otsirh/gazette.bg/issues/new?template=mistake.yml).

## Как работи

Всеки ден в 12:00 и в 17:00 UTC работният поток
`.github/workflows/update-gazette.yml` изпълнява `npm run update-gazette`:

1. **Изтегляне.** `scripts/download-latest-gazette.js` отваря dv.parliament.bg с
   Playwright и изтегля PDF файла на всеки от десетте най-нови броя, който още
   липсва в `issues/` — до два на изпълнение, като започва от най-стария.
   Записва и връзката към официалния PDF файл, и съдържанието на официалния
   раздел: всеки акт със страницата си и връзка към собствената му страница. Ако
   списъкът с броевете не се зареди, опитва още два пъти. Сайтът отговаря само
   на български адреси, затова в GitHub Actions браузърът излиза през Mac mini
   у дома — изходен възел (exit node) в Tailscale.
2. **Обобщение.** `scripts/summarize-gazette.js` минава всеки брой през три
   стъпки с Claude Opus, по указанията от `scripts/ai-prompts.js`:
   - **инвентар** — PDF файлът се чете на части по 50 страници и от всяка се
     изважда всичко, което може да засегне хората, ред по ред, със страницата;
   - **обобщение** — от целия инвентар се пише текстът; всяка секция завършва с
     ред „Източник: акт 2, стр. 37“, който сайтът превръща във връзки към
     официалния текст;
   - **проверка** — обобщението се чете срещу самия PDF и всяка грешна цифра,
     дата или страница се поправя. Поправките се записват в
     `<брой>.check.json` до обобщението, заедно с цената на броя.

   Резултатът е `issues/<година>/<брой>/<брой>.md`, а датата, официалният PDF и
   актовете — в `<брой>.json` до него. Брой, който не успее, се връща назад и
   се опитва отново при следващото изпълнение, без да спира останалите; след
   три неуспеха чака човек (`issues/.summary-attempts.json`), защото всеки опит
   струва пари.
3. **Теми.** `scripts/tag-topics.js` дава на всяка новина (## секция) една или
   две теми от фиксиран списък (`TOPICS` в `src/js/shared.js`) като ред
   „Теми: …“ в края ѝ. Чете само обобщението и струва около 3 цента на брой;
   пуснат без аргументи, тагва всеки брой, който още няма теми.
4. **Липсващи броеве.** `scripts/check-issue-gaps.js` отчита изпълнението като
   неуспешно, ако в номерацията липсва брой.
5. **Публикуване.** Новите файлове се записват в `main`. Cloudflare Pages
   изпълнява `npm run build` и публикува папката `dist/`: началната страница с
   новините от седмицата, страница за всеки брой и за всяка новина в него
   (`/issue/<година>/<брой>/<новина>/`), страница и RSS емисия за всяка тема
   (`/tema/<тема>/`), архива, общата RSS емисия, картата на сайта и индекса
   за търсене. Новините от последните 90 дни получават и картинка за
   споделяне, направена при сглобяването (`scripts/lib/share-images.js`).

## Локално

Нужен е Node.js 24.

```sh
npm ci
npm run dev       # сглобява dist/ и го показва на http://localhost:3000
npm run check     # проверка на кода (Biome) и тестовете
```

Сглобяването не изисква ключ. За изтегляне и обобщаване на нови броеве:

```sh
npx playwright install chromium
cp .env.example .env     # и попълнете ANTHROPIC_API_KEY
npm run update-gazette
```

## Структура

| Път        | Съдържание                                        |
| ---------- | ------------------------------------------------- |
| `issues/`  | Обобщенията, по една папка за брой                |
| `scripts/` | Изтеглянето, обобщаването и сглобяването на сайта |
| `src/`     | Шаблонът, стиловете и скриптовете на страницата   |
| `test/`    | Тестовете (`npm test`)                            |
| `dist/`    | Сглобеният сайт; не се пази в git                 |

## Поддръжка

- **Зависимости.** Dependabot предлага обновления веднъж седмично. Минорните
  версии и поправките се сливат сами, щом проверките минат; големите версии се
  обновяват ръчно.
- **Промени в указанията.** `node scripts/compare-summaries.js 2026/98 2026/99`
  пише ново обобщение на всеки посочен брой и дава и двете — публикуваното и
  новото — на Claude заедно с PDF файла за сляпа оценка, без да казва кое е
  кое. Така се вижда дали една промяна подобрява текстовете, преди да стигне до
  сайта. Струва около 4 долара на брой и спира при `--budget` (по подразбиране
  60). PDF файловете остават в `.eval/`, който не се пази в git: в тях има
  имена на частни лица.
- **Връзка с Claude.** Работният поток „API check“ (Actions → API check → Run
  workflow) изпраща една малка заявка по пътя на обобщаването. Полезен е след
  обновяване на `@anthropic-ai/sdk` и струва около цент.
- **Изходен възел.** Ако Mac mini е изключен, заспал или извън Tailscale,
  изпълнението спира още на стъпката „Connect to the exit node in Bulgaria“.
  Тайната `TS_OAUTH_SECRET` е OAuth клиент на Tailscale, който създава ключове
  с етикет `tag:ci`; променливата `TS_EXIT_NODE` е името на Mac mini в
  мрежата. Версията на Tailscale в работния поток се обновява ръчно.
